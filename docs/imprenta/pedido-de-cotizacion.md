# Pedido de cotización · Verdad o Deseo

Juego de cartas para adultos: un mazo de 60 cartas dentro de un estuche de cartulina.

## Cantidades a cotizar

50, 100, 300 y 500 juegos. Precio por juego en cada cantidad.

## Cartas

| | |
|---|---|
| Cantidad por juego | 60 cartas |
| Medida final | 63 × 88 mm, puntas redondeadas (radio 3 mm) |
| Impresión | 4/4 colores (frente y dorso a todo color) |
| Frentes | 60 distintos: fondo crema o rosa claro, texto y filete bordó |
| Dorso | Igual en las 60: fondo bordó pleno con monograma dorado |
| Papel | Cartulina para naipes de 300 a 350 g. Cotizar la opción que trabajen |
| Terminación | Laminado mate en ambas caras. Cotizar aparte barniz, si es más económico |
| Sangrado | 3 mm por lado (archivo de 69 × 94 mm) |

## Estuche

| | |
|---|---|
| Tipo | Estuche con solapa, pegado lateral, muesca para el pulgar |
| Medida armado | 65 × 90 × 20 mm (ancho × alto × fondo). El fondo se ajusta al grosor real del mazo |
| Impresión | 4/0 colores (solo exterior) |
| Papel | Cartulina de 300 a 350 g |
| Terminación | Laminado mate. Cotizar como opcional stamping dorado en los textos y filetes dorados |
| Troquel | El plano adjunto es de referencia. Si tienen un troquel propio de medida parecida, adaptamos el arte |

## Qué necesitamos que incluya la cotización

- Precio por juego en cada cantidad, con el mazo dentro del estuche armado.
- Si el estuche se entrega armado y con las cartas adentro, o por separado.
- Costo de matriz o troquel, si corresponde.
- Plazo de entrega desde la aprobación de los archivos.
- Si hacen prueba de color o muestra física antes de la tirada.
- Forma de pago y si el precio incluye IVA.
