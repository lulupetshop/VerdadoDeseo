# Verdad o Deseo

Tienda y landing de Verdad o Deseo: juego de preguntas y retos para parejas (+18).

## Estructura

- `assets/`, `blocks/`, `config/`, `layout/`, `locales/`, `sections/`, `snippets/`, `templates/`: tema Horizon de la tienda `verdadodeseo.myshopify.com`, exportado el 10/11/2026.
- `docs/`: brief, estructura de la landing, datos de Shopify y portadas.
- `prototipos/`: prototipo aprobado de la mesa 3D.

## Publicar un cambio

1. Trabajar en una rama, nunca directo en `main`.
2. Abrir un pull request hacia `main` y hacer merge.
3. Shopify publica solo el tema conectado a `main` (en uno o dos minutos).
